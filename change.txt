SUMMARY OF CHANGES
------------------------------------------------------------------------
1. Added `user_id` column to `users` table:
   - Type: VARCHAR(32) NULL UNIQUE
   - Placed after `id` column
   - Holds formatted, monotonic custom user IDs (e.g., "smart-lv-000001")
   - Added index `idx_users_user_id` for fast lookups by custom ID

2. Added `app_sequences` table:
   - Maintains independent, persistent, auto-incrementing counters
   - Used to generate "smart-lv-000001", "smart-lv-000002", etc.
   - Guaranteed that if a user is deleted, their ID is NEVER reused!


========================================================================
MIGRATION QUERIES FOR EXISTING DATABASE (RUN IN PHPMYADMIN / MYSQL)
========================================================================

-- 1. Add user_id column and index to existing `users` table:
ALTER TABLE `users`
  ADD COLUMN `user_id` VARCHAR(32) NULL UNIQUE AFTER `id`,
  ADD INDEX `idx_users_user_id` (`user_id`);

-- 2. Create the sequences table:
CREATE TABLE IF NOT EXISTS `app_sequences` (
    `seq_name`   VARCHAR(50) PRIMARY KEY,
    `last_value` INT UNSIGNED NOT NULL DEFAULT 0
) ENGINE = InnoDB;
